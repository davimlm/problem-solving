## 🧠 Tópicos Abordados

- **Strings** — manipulação, comparação, contagem de caracteres
- **Matemática** — paridade, divisão, progressões
- **Simulação** — execução passo a passo de algoritmos
- **Greedy** — decisões localmente ótimas
- **Matrizes** — navegação e contagem de movimentos
- **Sets** — caracteres únicos
